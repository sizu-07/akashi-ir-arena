# 投影画面用音声

投影画面で使用する音声素材は、このフォルダーへ保存します。

- `countdown/`: カウントダウンの音声や効果音
- `bgm/`: カウントダウン中などに流すBGM

推奨形式は MP3 または WAV です。ファイル名には半角英数字とハイフンを使用してください。

例:

- `countdown/countdown.wav`（現在使用中。数字の発声を含む一続きの音源）
- `bgm/countdown.mp3`

`countdown/countdown.wav` は、解析した発声時刻に合わせて投影画面の表示と同期します。音源を差し替えた場合は、表示時刻も再調整してください。
