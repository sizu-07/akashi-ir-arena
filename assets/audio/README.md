# 投影画面用音声

投影画面で使用する音声素材は、このフォルダーへ保存します。

- `countdown/`: カウントダウンの音声や効果音
- `bgm/`: カウントダウン開始から試合中に流すBGM

推奨形式は MP3 または WAV です。ファイル名には半角英数字とハイフンを使用してください。

例:

- `countdown/countdown.wav`（現在使用中。数字の発声を含む一続きの音源）
- `bgm/bgm.mp3`（現在使用中。試合中は繰り返し再生）

「表示を準備」を押すと両方の音源を読み込みます。`countdown/countdown.wav` は、解析した発声時刻に合わせて投影画面の表示と同期します。`START` の表示と同時に `bgm/bgm.mp3` の再生を開始し、試合終了または一時停止まで繰り返します。カウントダウン音源を差し替えた場合は、表示時刻も再調整してください。
