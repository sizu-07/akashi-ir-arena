# 投影画面用音声

投影画面で使用する音声素材は、このフォルダーへ保存します。

- `countdown/`: カウントダウンの音声や効果音
- `bgm/`: STARTから試合中に流すBGM
- `effects/`: 試合イベントの効果音。下表のファイル名で置くと、投影画面のスピーカーから再生する

推奨形式は MP3 または WAV です。ファイル名には半角英数字とハイフンを使用してください。

例:

- `countdown/countdown.wav`（現在使用中。数字の発声を含む一続きの音源）
- `bgm/bgm.mp3`（現在使用中。試合中は繰り返し再生）

「表示を準備」を押すと両方の音源を読み込みます。`countdown/countdown.wav` は、解析した発声時刻に合わせて投影画面の表示と同期します。`START` の表示と同時に `bgm/bgm.mp3` の再生を開始し、試合終了または一時停止まで繰り返します。カウントダウン音源を差し替えた場合は、表示時刻も再調整してください。

効果音は `effects/` に次の名前で保存します。各行は `.mp3` または `.wav` のどちらかを使用でき、両方ある場合は `.mp3` を優先します。

| ファイル名 | 再生する時 |
|---|---|
| `shot.mp3` / `shot.wav` | 銃の有効な射撃1回ごと |
| `hit.mp3` / `hit.wav` | ダメージ確定時。ただしHPが0になる命中では撃破音のみ |
| `defeat.mp3` / `defeat.wav` | 命中でHPが0になった時 |
| `revive.mp3` / `revive.wav` | 味方への3秒照射による復活が成立した時 |
| `match-end.mp3` / `match-end.wav` | 試合が終了した時 |

ファイルがない項目は無音です。ファイルの追加・差し替えはサーバー起動中にも検出します。投影画面で一度「表示を準備」を押して音声再生を許可してください。銃からは音を出しません。音量は元ファイルとPC・スピーカー側で調整してください。
