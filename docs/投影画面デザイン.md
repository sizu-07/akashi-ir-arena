# 投影画面のデザイン

対象は `/display`。赤（#ed2335）・墨黒（#141414）・生成り（#f4f1e9）を使用する。

## 構成

- 大きさと傾きを変えた文字、斜めの赤い面、紙面グリッド、網点、照準リング、動く細線、バーコードを組み合わせる。
- 時計・撃破数・HPを大きく表示。Aは白地、Bは黒地にし、チーム名も併記する。
- カウントダウンはサーバー時刻に合わせて3→2→1。細線リングとガイド線が動き、数字が切り抜きから飛び込む。秒ごとに角度・位置・補助文字を変える。
- 対戦開始時に短いGO演出、被弾時にカードの揺れ、撃破時にOUTの帯を表示する。
- ルール、一時停止、勝利、引き分けにも共通の文字組みと装飾を適用する。
- 暗転は文字・装飾・操作ボタンを含めて黒表示。試合終了後も運営の映像切替を優先する。
- `prefers-reduced-motion` 指定時はアニメーションを停止する。

## フォント

`apps/web/fonts/` に同梱し、会場でのインターネット接続やOSへのインストールを不要にした。

| フォント              | 用途                         | 配布元                                                             |
| --------------------- | ---------------------------- | ------------------------------------------------------------------ |
| Anton                 | 時計・スコア・カウントダウン | [Google Fonts](https://fonts.google.com/specimen/Anton)            |
| Barlow Condensed Bold | 英字見出し・補助情報         | [Google Fonts](https://fonts.google.com/specimen/Barlow+Condensed) |
| Noto Sans JP          | 日本語・参加者名             | [Google Fonts](https://fonts.google.com/specimen/Noto+Sans+JP)     |

取得元は [google/fonts](https://github.com/google/fonts) の `ofl/anton`、`ofl/barlowcondensed`、`ofl/notosansjp`。SIL Open Font Licenseの原文をそれぞれ `*-OFL.txt` に同梱する。

## 起動と確認

既存の `起動_デモ.cmd` または `npm run demo` で起動し、`http://localhost:8080/display` を開く。「表示を準備」を押して全画面・音声を有効にし、運営画面から試合を開始する。

画面の構造は `apps/web/display.html`、専用CSSは `apps/web/display.css`、状態表示・演出は `apps/web/display.js`。ゲームルールと既存の運営画面のCSSは変更していない。サーバーには専用CSS・アイコン・フォントの配信経路を追加した。

```powershell
node --test tests/*.test.mjs
node tests/browser.mjs
node tests/projector-browser.mjs
```

ブラウザーテストにはPlaywrightとMicrosoft Edgeが必要。Playwrightが別の場所にある場合は環境変数 `PLAYWRIGHT_MODULE` にそのモジュールの絶対パスを設定する。

追加テストは `artifacts/projector/` に各画面のPNGと結果JSONを出力する。1920×1080、1280×720、1024×768、2560×1080、390×844で表示を確認し、長い名前、HP1000、60分の時計、カウントダウンの再実行、暗転、勝敗、ルール、モーション低減を検証する。

実機プロジェクターでの明るさ・投影距離・音量は会場での確認が必要。
