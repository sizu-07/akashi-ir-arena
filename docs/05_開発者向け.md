# 開発者向け案内

[最初のページへ](../README.md)

## 必要な環境

- Windows 10または11
- Node.js 20以上
- ファームウェア開発時はPython、PlatformIO 6.1.18、pyserial 3.5
- 対象マイコンはXIAO ESP32-S3 Plus

## よく使う操作

```text
npm install       依存関係を取得
npm run demo      4丁を模擬してPCアプリを起動
npm test          ソフトウェアの自動テスト
npm run validate  テスト結果とハッシュをartifactsへ出力
```

GPIO構成の元データは `specs/hardware-profile.json` です。変更後は `node tools/generate-firmware-profile.mjs` を実行します。生成される `firmware/include/hardware_profile.h` を直接編集しないでください。

運営画面は `apps/web/index.html` と `apps/web/app.js`、投影画面は `apps/web/display.html` と `apps/web/display.js`、共通デザインは `apps/web/style.css` です。説明スライドは `apps/web/rules-content.js`、動画は `assets/rules.mp4` です。

秘密情報は `config/`、試合記録は `data/` と `logs/` に保存され、GitHubには含まれません。
