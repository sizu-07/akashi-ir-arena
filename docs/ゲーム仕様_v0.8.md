# 明石光線 ゲーム仕様 v0.8

## 試合と勝敗

- 4人の個人戦。全員が互いに攻撃できる。チームや味方撃ちの概念はない。
- 1ゲームの実時間は85秒、投影画面の時計は1分30秒から0まで表示する。合計4ゲーム。本番では第1〜3ゲームの後に、そのゲームの戦績と累計キル数を15秒表示し、次ゲームのカウントダウンへ自動で進む。投影画面や端末の準備が整わない場合は途中経過画面で待機し、復旧後に自動で進む。BGMはゲーム開始と同期し、停止後の再開時は停止した位置から再生する。
- 第4ゲーム後、4ゲームの合計キル数が最多の人を優勝者とする。最多キル数が同じ場合は同率優勝。デス数は順位判定に使わない。
- キル数、デス数、射撃数、命中率を各人ごとに記録する。命中率は「1人以上を撃破した射撃数 ÷ 全射撃数 × 100」。1発で複数人を撃破しても100%を超えない。

## 射撃・撃破・復活

- トリガー1回の押下で赤外線を1発送る。押し続けても追加発射しない。再射撃にはトリガーを離し、前回の射撃から0.7秒以上待つ。弾数は無制限。
- 赤外線受信部の前・左・右のいずれかに当たり、サーバーが発射記録と照合した時点で撃破が成立する。1発で複数の受信部が報告しても同じ人の撃破は1回とする。自分自身の赤外線は無効。
- 撃破された人は射撃できず、7秒後に自動復活する。復活回数は無制限。手動復活・味方の救助照射は使用しない。一時停止中は復活までの残り時間も停止する。
- 撃破中は銃のLEDを赤く点滅させ、振動を周期的に出す。復活時にはLEDと振動で通知する。

## 運営と端末

- 通常試合には4台の接続・時刻同期・端末構成の確認と、投影画面の準備が必要。運営画面の一時診断では接続端末同士で射撃・命中・7秒復活と振動を試せる。診断中は本番時計を止め、診断結果を試合スコアに加えない。
- デモでは現在のゲームだけを任意の時点で終了し、途中経過を確認して次ゲームを手動で開始できる。デモ・本番とも「試合全体を強制終了」は残りゲームを実施せず、現時点の累計キル数で試合を確定する。動作確認モードの強制終了では優勝者を決めない。
- 整理券の1枠は15分。通常の4ゲーム5分40秒、途中経過45秒、4回の開始カウントダウン約28秒で、試合進行は約6分53秒。残り時間を入退場と機材確認に使う。入場受付が4人揃うと名前を待機中の試合へ自動反映する。整理券枠の進行通知は第1ゲーム開始と試合全体終了に対応し、途中経過やゲーム間の自動進行では枠を切り替えない。
- 旧v0.7以前のチーム・HP制の保存試合は新ルールで再開せず、参加者名を引き継いで新しい待機状態にする。
- 端末への状態配信では `hp` を生存時1、撃破中0の互換フィールドとして用い、復活時刻を `respawn_at` で送る。得点と最終勝敗はサーバーが管理する。

## 処理の分担

| 場所 | 担当する処理 |
|---|---|
| マイコン | SW1の押下・チャタリング除去、0.7秒射撃間隔、38 kHz赤外線の送受信、受信形式・CRC検査、LED・振動、通信断時の射撃停止と黄色2回点滅、電池状態の測定・報告。命中候補と発射をPCへ報告する。 |
| PCゲームサーバー | 4台の接続・時刻同期・開始ACK確認、発射と命中候補の照合、自己命中と重複の排除、撃破・7秒復活・キル等の記録、85秒×4ゲームの時計、15秒の途中経過、勝敗、強制終了、状態保存と復旧。 |
| 投影・運営画面 | サーバー状態の表示、カウントダウン・効果音・通信断時の警告音・途中経過・結果の提示、運営操作の入力。警告音は音声を準備した投影PCのスピーカーから鳴る。表示側で得点や勝敗を確定しない。 |
| 整理券サーバー | 1枠15分・4席の受付と入場確認、参加者名の提供、第1ゲーム開始・一時停止・試合全体終了の通知による枠管理。ゲーム内の撃破判定は行わない。 |
