## 1. 部品と製作の準備

[部品候補表](../specs/component-plan.csv)を確認します。4丁分はXIAO Plus 4台、受信機12個、振動モーター4個です。アンテナは同梱品の有無を購入時に確認します。

**回路図・PCB・銃モデルは別担当者が新規設計します。現時点では製造用データがないため発注できません。** 全回路の部品数量、XIAO底面端子の引出し、モーター電源・駆動回路、3受信部とアンテナ・モーターの固定は、回路・筐体設計で具体化する必要があります。

基板が完成したら電源・極性・逆流防止・モーター起動ノイズを先に測定し、[完成確認チェック](04_完成確認チェック.md)を1丁で終えてから4丁へ展開します。

## 2. Buffalo WSR-2533DHP3で展示専用LAN

以下は設定方針です。**実際のルーターへログイン・変更はしていません。** 学校の既設ネットワークと混ぜず、管理権限のある展示専用ルーターを使います。

| 項目 | 設定 |
|---|---|
| PC接続 | ルーターLANポートへ有線。WAN側へ挿さない |
| 動作 | 展示専用LANのルーターモード、DHCPはこの1台のみ。インターネット接続は不要 |
| SSID | 2.4 GHz専用名を作る（例AKASHI-IR）、ESP32とiPadを接続 |
| 暗号化 | WPA2-PSK(AES)、固有の長いパスワード |
| 隔離 | ゲストポートを使わず、プライバシーセパレーターを無効にして端末間通信を許可 |
| PC IP | 現在のLAN範囲内でDHCP予約。192.168.11.10は例で、空き確認なしに固定しない |
| 無線 | 20 MHz幅、会場の混雑が少ないチャンネルを選ぶ。試合中に変更しない |
| 外部公開 | ポート転送なし、学校外インターネットへ公開しない |

メニュー名はルーターのファームウェアに依存します。[WSR-2533DHP3公式説明書一覧](https://www.buffalo.jp/product/detail/manual/wsr-2533dhp3-wh.html)と[プライバシーセパレーターの説明](https://www.buffalo.jp/support/faq/detail/16054.html)を併用します。PCの `ipconfig` でIPv4、サブネット、ゲートウェイを確認。

Windowsの**展示LANのみPrivate**にし、ファイアウォールを全面無効にしません。次は確認だけです。

```powershell
./tools/firewall.ps1 -Subnet 192.168.11.0/24
# 実際のサブネットと一致する場合だけ、管理者PowerShellで反映：
./tools/firewall.ps1 -Subnet 192.168.11.0/24 -Apply
```

Node実行ファイル・Private・そのサブネットからのTCP8080/1883に限定します。HTTP/MQTTはTLSなしなので、専用LANでも盗聴耐性を保証しません。公衆Wi-Fiでは使いません。



## 3. Plusへ書込み・Wi-Fi設定

コマンドはProjectの一番上のフォルダーで実行します。Node.js 20以上と依存関係（別PCでは `npm install`）、Python、PlatformIO 6.1.18、pyserial 3.5が必要です。

1. デモを終了し `起動_本番.cmd` を起動。PCの `http://localhost:8080/` にPINでログイン。
2. 「銃のWi-Fi設定を作成」へ2.4 GHzのSSID、パスワード、PCのIPv4を入力。`config/provision/gun-001.json`～`gun-004.json` を作ります。秘密情報は会話やGitHubへ貼りません。
3. 以前の設定ファイルはこの画面で再作成します。新しいファイルには `hardwareProfile: "xiao-s3-plus-3rx-motor"` が必要です。通常は `bench:false`、`adcScale:2.0`。
4. **Plusからすべての外部配線・電池・モーターを切り離し、USB Type-CデータケーブルだけでPCに接続**。元の38ピンボード・通常版XIAO・SenseにはこのBINを書きません。
5. `書込みとWiFi設定.cmd` を実行し、YES、COM番号、端末IDを入力。別PCの初回は `python -m pip install platformio==6.1.18 pyserial==3.5`。
6. 書込み後にCOM番号が変わる場合があります。デバイスマネージャーで実行用ポートを確認し、続く質問へ入力します。同じならEnter。
7. 「設定保存を確認」の表示まで待ち、USBを外してIDラベルを貼ります。実機への接続はv0.6回路の完成・電源検査後です。
8. 4台を別IDにし、接続4/4と「v0.6対応」、通常モード、電池警告なしを確認します。

書込みポートが現れないときはBOOTを押しながらRESETを押して離し、その後BOOTを離して再検出します。USB給電のみでボタン操作します。シリアルモニターは設定転送前に閉じてください。

再設定：
```powershell
python tools/provision.py --port COM5 --file config/provision/gun-001.json
```

USBだけの検証はJSONを `bench:true` にして保存します。このモードは電池警告を除外しますが、**発射・振動・試合開始はできません**。通常運用の前にfalseへ戻して再保存します。

## 4. 電池電圧の校正

NiMHは外部分圧・逆流遮断を経由してD0/GPIO1（ADC1）で測ります。XIAO搭載BAT電圧読取り用GPIO10は使いません。

新しい倍率 = 現在のadcScale × テスター実測電圧 ÷ PC表示電圧。2点以上で誤差を確認し、JSONを更新して再保存します。ソフトの許容倍率は1.0～4.0です。電池の実容量とモーター負荷が変わるため、旧計算の運転時間はそのまま使いません。
