# ① 概要と仕様（v0.6）

[最初のページへ](../README.md) ／ [製作手順](02_製作手順.md)

## 構成

- 4人・2対2。銃1丁ごとに **XIAO ESP32-S3 Plus 1台、OSRB38C9AA受信機3個、OSI5FU3A11C赤外線LED1個、振動モーター1個**。
- 受信部はすべて銃に取り付け、身体には付けません。配置の初期仕様は前（rx1）・左（rx2）・右（rx3）。取付位置・形状は今後のモデル更新と実測で決めます。
- 3受信機を独立して読みます。同じ射手の同じ弾が同じ銃の複数箇所に当たっても、HPを減らすのは1回です。受信箇所によるダメージ差はありません。
- Windows PCが命中・HP・弾数・得点・試合進行を確定。銃は通知された状態を反映します。
- Buffalo WSR-2533DHP3の2.4 GHz専用LANで接続。PCは有線、銃とiPadはWi-Fi。プロジェクターはメインPCの拡張画面です。

## 初期ルール

| 項目 | 値 |
|---|---|
| HP／ダメージ | 100／25 |
| 装弾数／リロード | 30発／2秒 |
| 最大発射頻度 | 5発/秒 |
| 命中後の無敵時間 | 300 ms |
| 味方撃ち／復活 | 無効／なし |
| 制限時間 | 5分 |
| 勝敗 | 撃破数 → 残HP合計 → 引き分け |

数値は開始前の運営画面で許可範囲のみ変更できます。銃の通信断・電池低下・対応構成の不一致は試合を一時停止。iPadだけの切断ではPCで試合が続きます。

## 光・音・振動

PCの命中確定でLEDを赤点滅、ブザーを鳴らし、モーターを180 ms駆動します。1回の駆動は最大250 ms、駆動開始間隔は最低300 msです。無敵時間を短くした場合でも振動はこの上限で間引きます。

味方撃ち無効時・不正な候補・同じ弾の重複・HPの運営補正・自分の発射では振動しません。致死ダメージでも通常と同じ振動です。停止・終了・通信断・電池低下・USB机上モードではOFFにします。古い命中通知は再生しません。

## マイコンと電源

Plusは16 MBフラッシュ、8 MB PSRAM、USB Type-C、2.4 GHz Wi-Fi搭載です。[メーカー仕様](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/)に従い、対応U.FLアンテナを接続します。アンテナも銃内に収容するスペースが必要です。

単3 NiMH 3本の交換式を維持します。XIAOへは保護・逆流防止を備えた5 V系、モーターへは専用3.0 V系を用意する要求です。**NiMH電池をXIAOのBAT端子へ接続しません。** 搭載充電回路は今回使用せず、電池は銃の外で専用充電器により充電します。

振動モーター候補はVybronics VC1030B028Fです。MOSFET駆動と逆起電力・ノイズ対策が必要で、GPIOへ直接接続しません。最終部品と電源・稼働時間は回路担当者が確定します。
