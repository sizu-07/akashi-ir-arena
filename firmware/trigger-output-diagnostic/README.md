# SW1連動出力テスト（旧4E赤外線基板）

`hardware/circuit/4E赤外線.kicad_pcb` の配線に合わせた診断ファームウェアです。現行のv0.7ハードウェア仕様とはピン配置が異なります。

| 機能 | 旧基板の接続 | 動作 |
| --- | --- | --- |
| SW1 | J8 / GPIO2 / `SW_TRIGGER` | GNDに短絡するとLOW。20 ms安定後に押下と判定 |
| モーター | J6 / GPIO9 / `MOTOR_PWM` / Q2 | SW1を押している間、HIGHで連続駆動 |
| 赤外線 | J5 / GPIO6 / `IR_TX` / Q1 | SW1を押している間、38 kHz・約33%デューティーの搬送波を出力 |
| テープLED | J7 / GPIO43 / `LED_DATA_3V3` | BTF-LIGHTING WS2812B ECO（DC 5 V）を先頭から8個、RGB=(51,51,51)の白色で点灯 |

SW1を離すと3出力を停止し、LEDへ消灯データを送ります。起動時にSW1が押されていた場合は動作せず、一度離してから押し直す必要があります。SW2/J9/GPIO5とSW3/J10/GPIO4は読み取りのみで、500 msごとの `STATE` に現在値を表示します。SW1の確定した変化と出力の切り替えは `EDGE` / `EVENT` として表示します。シリアル速度は115200 baudです。

赤外線は通信フレームではなく連続した38 kHz搬送波です。一般的な復調型赤外線受信器では連続搬送波が検出されない場合があります。LEDの20%は各色チャンネルの設定値51/255であり、実測照度の20%を保証しません。`STATE` の出力欄はソフトウェアによる設定値であり、モーター回転、LED発光、赤外線発光の実測結果ではありません。

LEDはGRB順・上位ビット先行の24 bit/個、1 bitあたり1.25 µs、送信後のLOWを300 µsとして送信します。J7の1番は+5 V、2番はデータ（テープのDIN側へ）、3番はGNDです。テープに印刷された矢印の入力側へ接続してください。8個の切り出し片を使用します。USB給電時もJ7の実電圧とデータ波形は未測定です。

書き込み時は電池・モーター・外部配線を外し、USBだけで接続し、COM3のSerial Monitorを停止します。出力テスト時は回路図どおりの電源と配線を使用してください。モーターと赤外線は押し続ける限り動作するため、短い押下から確認してください。

ビルド：`powershell -File tools/build-firmware.ps1 -Environment trigger_output_diagnostics -Python <Python 3.11のパス>`

書き込み：同じコマンドに `-Upload -Port COM3` を付けます。
