# 組み立て済み4E基板向けゲームファームウェア

この版は、現在の組み立て済み基板で通常の赤外線ゲームを実行するための保存済みプログラムです。PlatformIO環境名は `legacy_4e_game`、ソースは `src/main.cpp` と `include/legacy_4e_profile.h` です。従来の机上用 `legacy-motor-demo-6` とは別で、赤外線送受信とPCによる命中判定を使用します。2026年10月6日にCOM3のESP32-S3へ書き込み、書き込みデータのハッシュ一致を確認しました。マイコンのみ接続した状態のため、外部モジュールの実動作は未確認です。

## 実機の端子

| 機能 | XIAOのGPIO | 動作 |
|---|---:|---|
| SW1 / J8 | 2 | 発射ボタン。内部プルアップ、押下時LOW |
| SW2 / J9 | 5 | 状態を読み取って通信。ゲーム操作には使わない |
| SW3 / J10 | 4 | 状態を読み取って通信。ゲーム操作には使わない |
| 赤外線送信 | 6 | 38 kHz変調。攻撃と味方復活照射を送信 |
| 赤外線受信1・2・3 | 44・7・8 | 3方向の受信、受信部IDとともにPCへ報告 |
| モーター | 9 | 基板上のMOSFETへ5 kHz、8 bitのPWM |
| WS2812B ECOテープLED | 42 | 実機で点灯が確認されたDATA、8個 |
| 電池電圧監視 | 1 | 基板の1 MΩ / 100 kΩ分圧を11倍換算 |

保存されている4E基板CADにはLED DATAがGPIO43、GPIO42が未接続と記録されています。GPIO42で点灯したという実機確認を優先しました。基板の改造・配線変更内容はCADに反映されていません。今後のv0.7新基板用 `xiao_s3_plus` はGPIO割り当てが異なるため、この実機へ書き込まないでください。

## 試合中の動作

- Wi-Fi経由でPCのMQTTサーバーに接続し、銃IDと試合状態、時刻同期、HP、命中確定通知を受け取ります。通信・同期・構成・電池に異常があれば発射と振動を停止します。
- SW1を押すと赤外線の攻撃信号を1発送ります。20 msのチャタリング除去を行い、押し続けても連射しません。再発射にはボタンを離し、直前の発射から1秒以上経過した後に再度押す必要があります。途中の押下は予約しません。
- 発射を開始すると60 ms、PWM 220/255で振動し、8個のLEDをRGB各51/255の白色で約310 ms点灯します。押し続けると約150 ms間隔で味方復活用の別信号を送り、PCに保持状態を報告します。
- 3方向の赤外線受信部から有効なフレームを受けたら、受信部IDと送信銃ID・発射番号をPCに報告します。ダメージ、味方撃ち、無敵時間、HP、復活の成立はPCが判定します。確定した通常被弾で180 ms、PWM 255/255の振動を出します。
- カウントダウンの5から1で80 msずつ振動し、PWMを150→170→190→210→230/255と増やします。START時は180 ms、255/255。HPが0になると180 msの振動を2回、復活時は80 msを3回出します。各振動は最大250 msで、開始時刻を少なくとも300 ms離します。時間的に重なる通知は省略・上書きされることがあります。
- LEDの1個目は発射可能時の赤表示です。残り7個は通常時にチーム色のHPバー、カウントダウンは白、被弾は短い赤、死亡は赤点滅、復活進捗と復活直後は緑、停止中は青点滅、通信等の異常時は橙/青の交互表示です。射撃時の白表示は一時的にHPバーより優先します。
- 電池電圧は1秒ごとに報告します。現在の停止判定は3.3 V未満、3.0 V未満が3秒以上でラッチです。これらは新基板向けの暫定値を引き継いだもので、4E基板の電源・モーターの実測下限としては未検証です。供給電圧、レギュレータ出力、モーター電圧を実測し、実機使用前に閾値を確定してください。PWM比からモーター電圧や振動強度を断定できません。

この版はPCサーバーの既存のゲーム通信形式を使用します。サーバーが要求する `hardware_profile` 識別子は互換性維持のためv0.7版と共通ですが、物理GPIOとLED数は同一ではありません。ファームウェア識別子 `0.7.1-4e42` とビルド環境名で版を区別してください。

## 保存と確認

プロジェクト最上位で、次のコマンドはコンパイルだけを行います。生成物は `firmware/.pio/build/legacy_4e_game/firmware.bin` です。ビルドは実機への動作保証ではなく、赤外線の距離、受信3方向、電源変動、振動、テープLEDの表示は接続後に実測してください。

```powershell
pwsh -File tools/build-firmware.ps1 -Environment legacy_4e_game
```
