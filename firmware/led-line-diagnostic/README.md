# LEDデータ線の電圧診断（旧4E赤外線基板）

XIAO ESP32-S3 PlusのD6/GPIO43を、SW1を1回押すごとにLOW/HIGHへ切り替え、その状態を保持します。起動時はLOWです。モーター（GPIO9）と赤外線（GPIO6）は常にOFFです。WS2812の信号は送らないため、このコードでLEDテープは点灯しません。

GPIO43はUSB CDC初期化後にESP-IDFのGPIO APIでプッシュプル出力に設定し、最大ドライブ能力で駆動します。起動時に設定結果のエラーコードをシリアルへ表示します（成功は0）。
シリアルを後から開いても確認できるよう、現在の指示状態と初期設定の結果を2秒ごとに表示します。表示する `command` はソフトウェアの指示値で、端子電圧の実測値ではありません。

USBのみで基板を給電し、外部6 V電源・モーター・LEDテープ・赤外線配線を外して測定します。J7の3番をGNDとして、D6とJ7の2番（DATA）をテスターで個別に測ります。SW1を押した後は時間制限なく測定できます。

| 状態 | XIAO D6/GPIO43 | J7 2番 DATA |
| --- | --- | --- |
| LOW | 約0 V | 約0 V |
| HIGH | 約3.3 V | 約5 V |

J7の1番は+5 Vです。テスター先端で隣接端子を短絡させないでください。D6とJ7のDATAの一方または両方が切り替わらなければ、その測定値を記録してください。シリアル115200 baudにも現在の設定と期待電圧を表示しますが、電圧測定だけで判定できます。

ビルド：`pwsh -File tools/build-firmware.ps1 -Environment led_line_diagnostics -Python <Pythonのパス>`

書き込み：同じコマンドに `-Upload -Port COM3` を付けます。書き込み時はCOM3のシリアルモニタを停止してください。
