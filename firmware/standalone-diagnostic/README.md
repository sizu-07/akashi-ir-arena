# 4E基板の単体動作確認版

`standalone_diagnostics` / `standalone-4e42-3`。Wi-Fi・サーバー・電池監視による停止条件を使わず、保存済みのWi-Fi設定は変更しません。

2026年10月6日、版1でCOM3への書き込みとLED・赤外線送信・受信3系統の初期化成功を確認しました。版2ではシリアル出力を受信内容のみに変更しました。版3はRMTで取得できない入力変化を調べるため、GPIOのCHANGE割り込みによる `RX_EDGE` を追加しています。発光・振動・光学的な送受信は未検証です。

- SW1/J8/GPIO2を押している間、GPIO42のWS2812B ECO 8個を白色20%（RGB各51/255）で点灯し、GPIO9のモーターを5 kHz・PWM 220/255で駆動します。離すと消灯・停止します。起動時に押しっぱなしの場合は一度離してから押します。
- 同じ押下中、GPIO6から38 kHz変調のゲーム形式のテスト信号を250 ms間隔で送信します。受信部のAGCに連続搬送波が抑制されることを避け、送受信の照合に使えるフレーム形式で発光します。離した際、送信中の1フレームだけは最大90 ms以内に完了します。
- 赤外線受信はGPIO44・7・8の3方向。押下していない間も受信し、自分の送信・CRC不一致・未解読の信号も除外せず、RMTで取得したパルスを `RX_RAW` に表示します。`L9000,H4500` はLOWが9000 µs、HIGHが4500 µsという意味です。ゲーム形式に解読できた場合は `RX_FRAME` に16進数データと銃ID・発射番号等を追加表示します。
- シリアルモニターはCOM3・115200 bps。入力変化時の `RX_EDGE`、RMT取得時の `RX_RAW` と `RX_FRAME` を出力し、起動・定期状態・ボタン・送信・初期化エラーのログは出しません。入力が変化しない間は何も表示されません。受信内容の `firmware=standalone-4e42-3` で今回の版を識別できます。CHANGE割り込みのバッファが満杯になった場合は `RX_OVERFLOW` に取りこぼし数を表示します。割り込みで拾えない速さの変化、受信モジュールが検出しない光、起動前から継続しているLOW等は完全記録できません。

ビルド・書き込みはプロジェクト最上位で行います。

```powershell
pwsh -File tools/build-firmware.ps1 -Environment standalone_diagnostics -Upload -Port COM3
```

ゲーム用のプログラムは別の `legacy_4e_game` 環境に保存されています。
