# ハードウェア担当者用

回路設計と銃の3Dモデルは別担当者が作成します。`circuit/` に残るKiCadデータは旧構成です。

- 回路・PCBデータの提出先：`circuit/`
- 銃の3Dモデル・STL・組立図の提出先：`gun-model/`
- 共通の要求条件：`../specs/hardware-profile.json`
- 部品候補と変更点：`../specs/component-plan.csv`
- ゲーム・操作・表示条件：`../docs/ゲーム仕様_v0.7.md`
- 検査条件：`../tests/実機試験記録.csv`

現在の `circuit/` のKiCadデータは旧構成を含み、v0.7の実装確認済み回路ではありません。新設計では銃の操作入力をトリガー1個にし、リロード・モード用スイッチとブザーを設けず、6個のLEDと振動モーターを接続してください。銃IDとWi-FiはUSBで登録するため、組立後もUSB端子にアクセスできる筐体が必要です。電源の投入・遮断方法は回路・筐体担当者が確定してください。

担当者は採用部品、端子割当、電源定格、基板寸法、取付位置が確定した時点で、このREADMEも更新してください。特に射撃時の短い振動と赤外線送信が同時に動作する際の電圧降下を実測してください。
